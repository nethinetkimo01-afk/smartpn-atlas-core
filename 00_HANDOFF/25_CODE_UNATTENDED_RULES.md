# Code 無人值守規則（Jim 定案 2026-07-11）

Code 機 24 小時常開，專跑長時間背景任務。背景批次執行中：

1. 遇到任何需要選擇、確認、詢問的情況：不停下等待，直接採用預設值
   或最保守選項，繼續執行
2. 每一次自行決定，記入總報告「自行決定清單」：
   哪一步｜遇到什麼問題｜採用了什麼預設值｜為什麼
3. 預設值原則：不刪資料、不改既有計算邏輯、不碰生產機（ME129）、
   選影響最小的路徑
4. 唯一允許停下的情況：操作可能造成不可回復的資料遺失
   → 記錄後跳過該步，繼續後面的步驟
5. 批次途中確認的新規則/新決策，立即寫入 00_HANDOFF 並 push，再繼續

## ★ 伺服器缺陷閘門（GATE-1 定案 2026-07-14）
`hub_gate.py`（repo 根）是伺服器缺陷閘門，涵蓋 6 類：①編制表低權限/空月不 500
②寫入端點越權(read_only 打寫入必 403)③重算並發第二發 409(DB 原子鎖)
④垃圾 month → 4xx ⑤不存在 id → 404 ⑥全面 缺參數/錯型別/空資料 → 一律 4xx 不 500。
- **每批 server（app.py/database.py 端點）變更，push 前必跑 `python hub_gate.py` 全綠**（隔離副本，勿碰正式庫）。
- **新增 API 端點必納入閘門**（在 hub_gate 補對應斷言）；跑不綠不准 push。

## ★ 整合外框類測試升級（S-2 定案 2026-07-14）
整合外框（如 `/app` 殼 + iframe）類任務的 Playwright 驗收必須：
- (a) 斷言「當前可見 iframe 的**實際內容標題**」（讀 contentDocument.title），**不得只斷言 class**；
- (b) 資料集必含**多單位 / 多月份 / 缺資料月**（生產形狀），不可只測單一乾淨案例；
- (c) 頁內跳轉（深入頁）後，殼狀態與**返回路徑**（一鍵回頁簽首頁）全測；
- (d) 每條斷言留截圖。
- 禁「原始碼含字串」當通過條件——必須真實渲染/行為驗證。

## Image Generation Workflow (Confirmed Process)

### Tools
- Claude: defines content, writes ChatGPT prompt
- ChatGPT: generates image
- Iteration target: 2-3 rounds maximum

### Key Rules to Reduce Iteration
1. Always upload reference image to ChatGPT (keeps avatar consistent)
2. Prompt must specify exact layout, colors, emphasis words
3. Prompt must say "only change these specific things, keep everything else identical"
4. Red emphasis word must be identified before writing prompt
5. Never let ChatGPT reinvent the avatar or layout

### Prompt Template Structure
Line 1: "This is a continuation of my existing LinkedIn image series. Reference the attached image."
Line 2: Canvas size and background
Line 3: Avatar side - expression (THINKING or SMILING)
Line 4: Text side - all elements with exact colors
Line 5: Bottom bar - SmartPN Atlas left, Contact right
Line 6: "Only change [X]. Keep everything else exactly the same."

### Expression Selection
- Pain point / problem scenario: THINKING (hand on chin, eyes upper right)
- Solution / positive outcome scenario: SMILING (big open smile, eyes nearly closed)

### Color Rules
- Brand blue: #292394 (SmartPN Atlas, Footwear & Apparel label, Governed Shared Language)
- Emphasis red: same red for ALL emphasis words in one image
- Logic: one color = one message (e.g. Incomplete = TODAY = same red = connected story)

### Iteration Log S01
Round 1: First draft - avatar too small, wrong position
Round 2: Avatar larger, added lists
Round 3: Added Updated by You / Updated by Supplier headers

### Lessons Learned
- Avatar must be large and dominant from round 1
- Reference image is mandatory - never skip
- Identify ALL color rules before starting prompt
- Bottom bar layout (logo left, contact right) is standard for all future images
- CR logo: remove from all future images

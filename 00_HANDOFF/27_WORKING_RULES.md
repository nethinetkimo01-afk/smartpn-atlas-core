# SmartPN Atlas — 工作規則與錯誤預防（2026-06-16定案）

## Claude 的錯誤檢討

### 錯誤清單
1. Jim 給了標準界面 xlsx，沒有第一天就完整讀完每個格子，靠記憶和猜測給 Code，導致整個禮拜在糾錯
2. Jim 說的每句話當聊天處理，沒有立刻記錄進 GitHub
3. 每次只修 Jim 指出的問題，沒有整體對照標準界面，越修越偏
4. 在 Jim 沒確認前，自己決定給 Code 執行
5. 不懂的不說，靠猜，猜錯了再改

### 違反 Jim 工作模式
- Jim 說：先定義目標→確認輸出→拆步驟→分工具。Claude 沒做到，直接跳去執行
- Jim 說：給一個結果，再問意見。Claude 給的是猜測，不是讀完檔案後的精確結果
- Jim 說：Jim 的話不是聊天。Claude 當聊天

## 永久規則（任何新視窗必須遵守）

### 規則1：先讀檔案才能動
任何涉及界面/欄位/格式/公式的任務：
必須先用 Python 讀取來源 xlsx
取得精確數據後
出預覽給 Jim 確認
Jim 說 OK 才給 Code

### 規則2：Jim 的話立刻記錄
Jim 說的每句話 = 重要資訊，不是聊天
重要決定 → 當場寫進交接文件 → push GitHub
不是對話結束才整理

### 規則3：確認前禁止執行
在 Jim 確認前：
禁止給 Code 任何執行指令
禁止自己決定任何格式或邏輯

### 規則4：不懂就說
不猜，不假裝懂
直接說「這個我不清楚，請你說明」

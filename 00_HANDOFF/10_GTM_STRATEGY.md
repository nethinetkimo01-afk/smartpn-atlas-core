## Core Strategy: Three Parallel Lines

Every Scenario produces THREE outputs from ONE source definition.
The content core is identical. Only the format changes.

### Line 1: LinkedIn Content (Attract strangers)
- Format: Attractive image + short caption
- One post = one Scenario
- Target: Footwear and apparel industry professionals
- Message: This is for footwear and apparel. Shared Language is not enough. You need GOVERNED Shared Language. Come to SmartPN Atlas to learn more.
- Goal: Someone sees a post, thinks "I need this function", contacts us

### Line 2: Presentation (Handle interested customers)
- Format: PPT slides, one page per Scenario
- Used when customer contacts us
- Must be ready before anyone contacts us
- Logic clear, numbers speak, short explanation

### Line 3: Demo Software (Close pilot run customers)
- Format: Working software
- Used when customer wants to run a pilot
- Must be ready before anyone asks
- White background, shopping website style, familiar interface

## Execution Rule
One Scenario at a time. For each Scenario, produce:
1. Scenario definition (JSON) ??single source of truth
2. LinkedIn image + caption
3. PPT slide
4. Demo screen

All three must be consistent. Same numbers. Same logic. Same message.

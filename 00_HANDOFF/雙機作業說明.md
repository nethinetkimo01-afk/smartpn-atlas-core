# 雙機作業說明（Code 機 ↔ 結果機）

Version: v1.0 | 2026-06-13
目的：一台機器晚上跑任務（Code 機），一台機器早上看最新結果（結果機），兩機分工不互卡。

---

## 兩台機器角色

| 機器 | 路徑 | 角色 | 開關機 |
|------|------|------|--------|
| **Code 機** | `C:\smartpn-atlas-core` | 晚上跑任務（Claude Code 後台執行、IE 導入、commit + push） | **不關機** |
| **結果機** | `D:\smartpn-atlas-core` | 早上執行 `sync.bat` 拉最新程式碼、看 Demo / IE / 勾選分配結果 | 早上開機即可 |

---

## 同步機制（兩條獨立管線）

### 1) 程式碼 — 自動同步（git）
- Code 機：每完成一個任務立刻 `git pull --rebase origin main` 後 `git push`。
- 結果機：早上執行 **`flask_backend\sync.bat`**（雙擊）即 `git pull origin main` + 重啟 Flask。
- GitHub = 唯一真實來源（single source of truth）。

### 2) DB（`*.db`）— 手動同步（隨身碟）
- **DB 不進 git**（`flask_backend/data/*.db`、`*.db` 已 gitignore，避免大檔 / 衝突）。
- Code 機跑完 IE 導入後，把 **`flask_backend\data\*.db`**（主要是 `atlas.db`）
  用隨身碟複製到結果機**同路徑** `D:\smartpn-atlas-core\flask_backend\data\`。
- 口訣：**程式碼自動同步，DB 手動同步。**

> 為什麼 DB 手動？資料庫是大型二進位檔，且由匯入腳本在 Code 機產生；
> 放進 git 會撐爆 repo 又常衝突。隨身碟複製最單純可靠。

## 結果機每日早上 SOP

1. 開機、登入。
2. 雙擊 `D:\smartpn-atlas-core\flask_backend\sync.bat`
   → 自動 `git pull` + 重啟 Flask，視窗會印出可開的網址。
3. （若 Code 機昨晚有跑導入）插隨身碟，複製 `atlas.db` 覆蓋到
   `D:\smartpn-atlas-core\flask_backend\data\`，再跑一次 `sync.bat` 重啟。
4. 開瀏覽器：
   - `http://localhost:5000/ie` — IE 主表
   - `http://localhost:5000/ie/matrix` — 矩陣
   - `http://localhost:5000/allocation` — 勾選分配系統
   - `docs/preview/SMARTPN_DEMO.html` / `SMARTPN_DEMO_SUPPLIER.html` — Demo（直接開檔即可）

## 自動化（選用）— 免每天手動點

結果機可讓晨間同步自動跑（擇一）：

**A. 工作排程器（每天 08:00，需管理員）**
```
python D:\smartpn-atlas-core\nightly\morning_sync.py --install
```
移除： `python ...\morning_sync.py --remove`
手動測試： `schtasks /run /tn Atlas_Morning_Sync`

**B. 啟動資料夾（登入後執行，免管理員）**
```
python D:\smartpn-atlas-core\nightly\morning_sync.py --startup
```
→ 會在「啟動」資料夾放一個 .bat，下次登入自動 `git pull` + 重啟 Flask。

`morning_sync.py` 一次性手動執行： `python D:\smartpn-atlas-core\nightly\morning_sync.py`
（它只殺舊 Flask、不殺自己；DB 仍需手動同步。）

## 注意事項

- `sync.bat` / `morning_sync.py` 內的 `taskkill /f /im python.exe` 會關掉**所有** python；
  結果機平常只跑這支 Flask，所以安全。若結果機另有 python 工作，先確認。
- Code 機與結果機都用 `git pull` 前請確保本地無未提交變更（結果機原則上只讀、不改碼）。
- 員工 / 多人連線：統一用 `http://<電腦名稱>:5000`（IP 浮動已棄用）。
- 對應檔案：`flask_backend/sync.bat`、`nightly/morning_sync.py`、本說明。

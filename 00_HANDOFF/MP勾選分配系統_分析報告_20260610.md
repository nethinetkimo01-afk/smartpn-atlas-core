## 一、目標鏈路（Jim 2026-06-10 口述）

```
DS-04 進度表（手工，格式固定不變）
   ↓ 已有：auto_bianche（LEAN / ART / 訂單）
廠務編制各部門生產明細
   ↓ 從 ob_epph 帶入 IE 同源 MP（cutting / stitching / assembly）
   ↓ 3 個勾選表：同材共裁自動化 / 電腦針車折邊 / 打粗水洗照射
勾選部位 → 該部位 MP 從 CSA 對應段扣除 → 移到外單位
   ↓
CSA 各部門淨 MP = IE 整線 MP − 勾走 MP  ←←← 這就是廠務編制表的數字
```

**核心發現：這條鏈路直接回答了 PENDING 已久的 MP 差距問題。**
ob_epph（整條線 MP）與廠務編制表（2~3 倍差距）的差，就是被勾走到外單位的部位 MP。
證據：標準 IE 檔（LA TRAINER, header 32, 22 sheets）本身就有 ATOM / 自动裁 / 电脑针车 / 同材共裁 獨立 sheet — IE 表已內建拆分，勾選機制只是把它數位化。

## 二、兩份手工表逆向解析（公式皆用真實數字驗證, Rule 17）

### 表 A：打粗 / 水洗 / 組底面照射

Sheets：SL (TĐ 16.05)（訂單來源, Tổ 別 PPH 表）/ SUM / 06月_打粗（340行）/ 06月_水洗 / 06月_组底面照射

行結構（打粗、照射相同）：
`序号 | Lean | 贴底组(Tổ) | 鞋型 | 訂單 | 流程名稱 | TCT秒/双 | Target Output | 需求人力 | 備註`

**公式（已驗證）：**
```
Target Output = 3600 ÷ TCT
需求人力     = 訂單 ÷ Target Output ÷ 月總工時
月總工時     = 8H × 25.5天 + 18H加班 = 222（全表固定）
```
驗證：TOKYO W，訂單145,839，TCT=18.9 → 145839÷190.476÷222 = 3.4489 ✓（與 J4 完全一致）
照射驗證：TECH RESPONSE，16428÷101.124÷222 = 0.7318 ✓

操作分類（打粗 sheet 固定兩段一組）：
- 打粗段：RB打粗 / CMEVA打粗 / Mài thô dây viền đế（沿條打粗）
- 吹尘配双段：Xịt bụi + phối đôi（固定 TCT=4, Target=900）
- 每鞋型底部 Total MP 行加總

水洗：不按 TCT，整段固定 5 人（大機器 3+2），手工備註。
SUM 月度匯總：打粗 49.32 + 水洗 5 + 照射 19.91 = 77.23 人；訂單分 EVM 生產(621,463) + GCN 外包(149,612)。

### 表 B：電腦針車 / 折邊

Sheets：06月_电脑针车（392行）/ 06月_电脑针车(2) / 06月_折边 / SUM_06月 / 生管安排上班时数_电脑针车

行結構：
`序号 | LEAN | 鞋型 | ART | 訂單 | 配件(操作) | TCT | Target Output | K需求人力 | EOLR | N需求人力 | 機器名稱 | 備註`

**兩套人力算法並存（已驗證）：**
```
K欄（按月訂單）：訂單 ÷ (3600÷TCT) ÷ 該LEAN月工時
                月工時 = 天數×7.5H + 該LEAN加班時數（生管安排上班时数 sheet，per-LEAN）
                例：1A ≈ 206H（反推驗證 K5=0.05186 ✓）
N欄（按線速）  ：TCT × EOLR ÷ 3600
                驗證：GAZELLE GOLF TCT=6.82, EOLR=75 → 0.14208 ✓（= 標準 IE 公式）
```

操作關鍵字（實際出現頻次統計）：
- 電腦針車類：三饰条电脑针车(43) / MVT 3 dây TT(36) / 前片电脑针车 / 领口泡棉电脑针车 / MVT nắp mũi
- 热切類：热切:三饰条(18) / Cắt 3 dây trang trí(15) / Cắt nhiệt đai lưỡi gà
- 折邊類：折边盖鞋舌 / Gấp biên / 擦胶 Quét keo（機器=Thủ công 手工）

機器只有 3 種：中型电脑针车(127) / 热压机(22) / 小MVT(2)。
LEAN 覆蓋 23 個組（1A~11B2）。
SUM：电脑针车 105.3 + 仓库生管 18 + 折边 21 + 水蜘蛛/返修/剪线等固定人力 = 165.3 人。

## 三、三張表的共同骨架（自動化的基礎）

| 維度 | 打粗/照射 | 電腦針車/折邊 | 共同點 |
|------|----------|--------------|--------|
| 行單位 | 鞋型×操作 | 鞋型×配件操作 | 操作明細為最小單位 |
| 來源 | DS-04 訂單 + IE TCT | DS-04 訂單 + IE TCT | 同源 |
| 人力公式 | 訂單÷(3600÷TCT)÷222 | K：同左(工時per-LEAN)；N：TCT×EOLR÷3600 | TCT 為核心 |
| 分組 | 贴底组 Tổ（≈DS-05 T組？） | LEAN | 需統一 |
| ART欄 | 無（只有鞋型名） | 有 | 表A需靠鞋型名匹配 |

**手工表非標準化的具體坑（解析時需處理）：**
1. 多 LEAN 合併一格：「2B, 7B, 8C, 9B, 11A2, 11C」「1A,2C」→ 扣 MP 回 CSA 時需拆分
2. 多鞋型合併一格：「TOKYO W\nTOKYO MJ W\nTOKYO W NAT」
3. 表A 無 ART 欄 → 鞋型名匹配（同 normKey 清理邏輯）
4. GCN 外包訂單混在表內（打粗 15 萬双）→ 外包單不在產線上，MP 是否從 CSA 扣？
5. 大小寫/全半形不一致：Tổ 9 / TỔ 9、CMEVA打粗 / CMEVA 打粗
6. 水洗為固定人力，不走 TCT 公式

4. **GCN 外包訂單**：外包單的操作 MP 不從 CSA 扣（人不在產線）？還是照扣？

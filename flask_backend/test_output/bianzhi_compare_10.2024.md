## 四、差異根因分析

| 根因 | 影響範圍 | 修復條件 |
|------|---------|---------|
| `bianche_lean_hc` 無 2024-10 | CSA direct_this = 0（正確值 2279） | 在 ME129 執行或從歷史資料匯入 |
| `ds04_orders` 無 month 欄 | 引擎取全部 2026 訂單而非 2024-10 | DB schema 需增加 month 欄，或按 delivery_date 篩選 |
| `lean_eolr_settings` 無 2024-10 | 全 LEAN 使用預設 EOLR=120 | 補入 2024-10 EOLR 設定 |
| `allocation_item` 無 2024-10 | 外移欄 P/Q/R 全 0 | 補入 2024-10 allocation 資料 |
| `bianzhi_unit_manual` 無 2024-10 | 大底課/自動化等單位直工/間工 = None | 從歷史資料或手工匯入 |
| `bianzhi_monthly_manual` 無 2024-10 | avg_lc/發外工時/扣減工時 = 0 → 效率公式無法計算 | 同上 |
| LEAN 編碼細分差異 | 引擎 3A/3B/10A/10B/10C，Excel 有 3A1/3A2/3B1 等 | ds04_orders 的 lean 欄需補細分代碼 |

**此對比在 Code機（開發機）執行。ME129 為真實資料主機；完整有效對比需在 ME129 匯入 2024-10 歷史資料後重跑。**
